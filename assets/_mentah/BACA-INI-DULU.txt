===========================================================
  TARUH GAMBAR DI FOLDER INI
===========================================================

Cara pakai:

  1. Beri nama file gambar sesuai KODE di bawah
  2. Taruh di folder ini (assets\_mentah)
  3. Klik dua kali file  "siapkan-gambar.bat"  di folder utama
  4. Selesai - gambar otomatis dikecilkan, dikompres,
     di-rename, dan index.html diperbarui sendiri

-----------------------------------------------------------
  KHUSUS 2 SURAT (tidak lewat skrip, tidak pakai kode)
-----------------------------------------------------------

  Dua kartu surat di halaman memakai file PDF, bukan gambar.
  Jadi TIDAK perlu ditaruh di folder ini dan TIDAK diproses
  oleh siapkan-gambar.bat. File-nya sudah terpasang:

    assets\bukti\surat-keterangan-pelatihan.pdf
        -> kartu surat di LAKES (masa pelatihan)

    assets\bukti\surat-keterangan-kerja.pdf
        -> kartu surat di GANESHA OPERATION (masa kerja)

  Kalau mau mengganti isinya, timpa file itu dengan nama yang
  sama persis. Kalau suratnya masih berupa foto, ubah dulu
  jadi PDF - bisa lewat Word, Google Docs
  (File > Download > PDF), atau HP (Print > Save as PDF).

  Tombolnya membuka PDF di tab baru. Karena filenya ada di
  folder website, alamatnya bisa diakses siapa pun yang tahu
  - jadi sensor bagian yang tidak ingin dipublikasikan.


-----------------------------------------------------------
  FOTO PROFIL (di hero, tidak lewat skrip)
-----------------------------------------------------------

  Foto yang tampil bulat di bagian atas halaman (hero):

    assets\foto-profil.jpg

  Sekarang isinya masih gambar contoh (siluet). Ganti dengan
  fotomu sendiri: timpa file itu, nama harus tetap
  "foto-profil.jpg". Tidak perlu dikecilkan dulu, tapi foto
  yang sisi terpanjangnya sekitar 800-1200 px sudah lebih
  dari cukup.

  Tips: pakai foto setengah badan yang mukanya kelihatan,
  latar polos. Foto ini dipotong bulat otomatis, jadi
  bagian tengahnya yang paling penting.


Contoh penamaan file:

  b4.jpg        ->  piagam webinar
  b5.png        ->  artikel
  l3.png        ->  logo Ganesha Operation

Huruf besar/kecil tidak masalah. File yang namanya tidak
diawali kode akan dilewati dan diberi tahu di layar.


-----------------------------------------------------------
  YANG DILAKUKAN SKRIP OTOMATIS
-----------------------------------------------------------

  - Foto dirapikan otomatis kalau posisinya miring
    (membaca data EXIF dari kamera HP)

  - Ukuran akhir gambar bukti: 1600 x 900 piksel (16:9)
    Gambar muat (fit) di tengah kanvas, jadi TIDAK ada
    bagian yang terpotong

  - Ukuran akhir logo: 320 x 320 piksel (kotak), latar
    transparan. Pinggiran logo yang kosong/putih dipotong
    otomatis dulu, jadi logo apa pun bentuk aslinya (JPG,
    screenshot, PNG berbingkai putih) hasilnya seragam dan
    tandanya tampil besar.

    Di halaman, logo dipasang di lencana BULAT 58px berlatar
    putih dengan cincin terracotta tipis - senada dengan foto
    profil di hero. Jadi kirim logo apa adanya saja.

  - Gambar bukti dikompres jadi JPEG kualitas 85%
    Logo disimpan sebagai PNG

  - index.html diperbarui otomatis, tidak perlu edit manual
    (cadangan lama disimpan sebagai index.html.bak)


-----------------------------------------------------------
  PENTING - SENSOR DULU SEBELUM DITARUH
-----------------------------------------------------------

  Dokumen internal (system design) dan surat keterangan TIDAK memakai gambar
  sama sekali, jadi tidak ada yang perlu ditaruh di folder ini. Kalau
  sewaktu-waktu mau dipratinjau, sensor dulu:
    - nama client / merchant
    - harga dan angka transaksi
    - data pelanggan
    - URL internal atau alamat server

  Untuk piagam dan sertifikat:
    - tanda tangan
    - nomor sertifikat
    - QR code

  Skrip ini hanya mengecilkan gambar. Tidak bisa menghapus
  atau menyensor isi gambar. Sensor dulu di aplikasi lain,
  baru taruh di sini.


-----------------------------------------------------------
  KALAU INGIN MENGUBAH CARA KERJA
-----------------------------------------------------------

  Buka PowerShell di folder utama, lalu jalankan:

    .\siapkan-gambar.ps1                    (setelan standar)
    .\siapkan-gambar.ps1 -Mode crop         (penuhi kanvas, pinggir terpotong)
    .\siapkan-gambar.ps1 -Quality 75        (file lebih kecil, kualitas turun)

  Mode "fit"  (standar) = gambar utuh, tanpa bingkai kosong
                          (paling aman untuk sertifikat & dokumen)
  Mode "pad"            = gambar utuh, ada bingkai kosong 16:9
  Mode "crop"           = kanvas penuh, pinggiran terpotong
                          (bagus untuk FOTO, jelek untuk dokumen)

  Catatan: mode itu hanya berlaku untuk gambar bukti (b1-b14).
  Logo (l1-l5) selalu diproses sama: dipotong pinggirannya lalu
  dibuat kotak 320 x 320.
